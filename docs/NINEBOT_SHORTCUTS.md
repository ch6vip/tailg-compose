# 九号控车快捷键

九号风格控车页的分隔线右侧提供「编辑」入口。底部三个位置默认依次为感应解锁、电池信息、打开坐垫。

- 先选择左侧、中间或右侧，再选择功能。选择已在其他位置的功能会交换两个位置，不产生重复快捷键。
- 再次选择当前功能或选择「留空」可移除该快捷键；主页保留添加入口，点击即可重新配置。
- 「恢复默认」重置编辑中的排列；「保存布局」成功后才应用。关闭面板放弃尚未保存的修改。
- 配置通过 DataStore 按车辆 key 本地保存。切换车辆时关闭旧编辑面板，读取对应车辆的布局。
- 编辑只修改入口，不执行感应解锁设置变更或坐垫指令。坐垫入口仍使用原有可用性、执行状态和指令回调。
- 读取失败可重试，保存失败保留草稿。未知或重复的存储功能标识会变为空位。

实现位于 `NinebotControlSection.kt`、`NinebotShortcutEditor.kt`、`NinebotShortcut.kt` 与 `NinebotShortcutStore.kt`。编辑面板支持中英文、深浅主题、系统字体缩放，并使用 Lucide 图标。

回归测试覆盖车辆配置恢复、并发保存、损坏数据、保存失败重试、取消编辑、位置交换、空位添加、车辆切换及执行状态。原生页面预览输出到被 Git 忽略的 `app/build/reports/ninebot-shortcuts/`。
